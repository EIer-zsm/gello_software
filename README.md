DOBOT Nova 2 Teleoperation

This repository contains a customized GELLO-based teleoperation system for the DOBOT Nova 2 robotic arm, integrated with the MS42DC gripper. It supports real-world leader-follower teleoperation and provides the foundation for standardized robotic data collection and imitation learning experiments.

For hardware setup, calibration procedures, and operation instructions, see Nova 2 Teleoperation and Calibration Guide.
